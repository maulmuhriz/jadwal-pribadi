Belum terhubung. Siapkan Google Calendar API dan OAuth Client ID terlebih dahulu.

Gunakan OAuth Client ID tipe Web application dengan origin resmi https://maulmuhriz.github.io. Jangan masukkan Client Secret di sini. Token akses hanya disimpan sementara di memori halaman; setelah halaman dimuat ulang, hubungkan kembali bila diminta.
